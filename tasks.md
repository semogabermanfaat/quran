# Tasks

Pelacak tugas untuk agen AI. **WAJIB diperbarui** pada setiap sesi kerja (lihat `AGENTS.md`).

## Aturan Pengisian

- Setiap tugas yang dikerjakan agen **wajib dicatat** di file ini.
- Tambahkan baris baru di bagian *Aktif* saat mulai mengerjakan, lalu pindahkan ke *Selesai* saat selesai.
- Format per tugas:
  ```
  - [ ] Deskripsi tugas — file yang diubah (baris) — status
  ```
- Gunakan `- [x]` untuk tugas selesai, `- [ ]` untuk belum/sedang dikerjakan.
- Sertakan nomor baris/lokasi yang diubah (mengacu ke `index.html`, lihat `README.md`).
