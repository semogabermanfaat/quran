# Al-Quran · Immersive 📖✨

Aplikasi web Al-Quran interaktif yang dirancang untuk memberikan pengalaman membaca dan mendengarkan Al-Quran yang tenang, estetis, dan mendalam. Dilengkapi dengan latar animasi bergerak, suara alam ambien, dukungan PWA (dapat diinstal di HP/TV), serta navigasi penuh menggunakan *Remote Android TV*.

🔗 **Live Demo:** [https://semogabermanfaat.github.io/quran](https://semogabermanfaat.github.io/quran)

---

## ✨ Fitur Utama

- **Audio Qori Pilihan**: Mendukung berbagai qori internasional populer seperti Mishary Alafasy, Abdul Basit (Murattal & Mujawwad), Al-Husary, Al-Minshawi, As-Sudais, dan Yasser Al-Dosari.
- **Multi Sumber API Al-Quran**: Dapat beralih antara database EQuran.id (Standar Kemenag RI), QuranJSON, dan AlQuran.cloud langsung dari menu setelan.
- **Latar Animasi Bergerak & Wallpaper Custom**: 
  - Pilihan tema animasi hidup (Malam berbintang, Fajar, Masjid, Hutan dengan kunang-kunang, dan Pantai berombak).
  - Fitur wallpaper kustom yang mendukung penarikan gambar langsung dari tautan Pinterest atau web (`pin.it` / `.jpg`).
- **Suara Alam Ambien (Relaksasi)**: Fitur audio latar belakang seperti Hujan, Petir, Air/Ombak, Hutan, dan Api Unggun untuk menemani tadarus.
- **100% Dukungan Remote TV (D-Pad)**: Navigasi penuh menggunakan tombol arah (Atas, Bawah, Kiri, Kanan) dan tombol OK pada remote Android TV tanpa terjebak di teks.
- **PWA (Progressive Web App)**: Dapat diinstal langsung ke perangkat Android atau TV layaknya aplikasi native.
- **Kustomisasi Tipografi**: Pengaturan skala ukuran dan pilihan font Arab (Amiri, Noto Naskh, Scheherazade, Lateef) serta terjemahan secara terpisah.
