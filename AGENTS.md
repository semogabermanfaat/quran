# Aturan Kerja Agen

## Kewajiban Utama

- **WAJIB baca `README.md`** sebelum mengerjakan tugas apa pun. README berisi peta lokasi kode (`index.html`) — gunakan untuk menemukan lokasi, JANGAN mencari-cari dengan grep/scroll seluruh file.
- **WAJIB isi `tasks.md`**: catat setiap tugas yang dikerjakan (tambahkan ke bagian *Aktif* saat mulai, pindahkan ke *Selesai* saat selesai) beserta file & baris yang diubah.
- Laporkan perubahan di akhir sesi: file apa yang diubah, di mana (baris), dan hasil pengujian.

## Hemat Kuota

- Periksa hanya file yang relevan dengan tugas.
- Jangan membaca ulang seluruh proyek tanpa alasan.
- Sebelum mengedit, buat rencana singkat.
- Ubah sesedikit mungkin file.
- Jangan menulis ulang file yang sudah benar.
- Jangan menjalankan build berulang kali tanpa perubahan kode.
- Maksimal dua percobaan perbaikan otomatis untuk satu error.
- Jika masih gagal, berhenti dan jelaskan error beserta penyebabnya.
- Jangan membuat fitur tambahan di luar permintaan.

## Konvensi

- Semua komentar & teks UI berbahasa Indonesia.
- Aplikasi adalah satu file `index.html` (HTML+CSS+JS). Jika menambah file baru, perbarui peta di `README.md`.
